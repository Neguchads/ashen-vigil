# Origem dos modelos usados em execução

Todos os modelos selecionados são CC0 1.0. Consulte `../../CREDITS.md` e
`../../docs/ASSETS.md` para autoria, links, limitações e uso.

`manifest.json` contém o tamanho, SHA256 e caminho do arquivo original na
biblioteca local. Arquivos `.import` são configurações geradas pelo Godot.
